POLÍTICA DE ATUALIZAÇÃO DA BASE — HEALTHCHECK IA

1. RASTREABILIDADE

Todo documento deve possuir, sempre que disponível:

- título;
- instituição/fonte;
- URL original;
- tema;
- subtema;
- data de acesso.


2. FONTES PRIORITÁRIAS

A base deve priorizar fontes oficiais e instituições
reconhecidas na área de saúde.

Na versão atual, são utilizadas fontes como:

- Ministério da Saúde;
- Anvisa;
- Fiocruz;
- INCA;
- OMS;
- OPAS.


3. REVISÃO PERIÓDICA

Os documentos da base devem ser revisados periodicamente
para verificar se:

- a página original continua disponível;
- o conteúdo foi atualizado;
- a recomendação permanece válida;
- o endereço da fonte mudou;
- surgiram novas orientações relevantes.


4. ATUALIZAÇÕES CRÍTICAS

Informações que possam mudar rapidamente devem receber
prioridade de revisão.

Exemplos:

- vacinação;
- surtos e epidemias;
- medicamentos;
- recomendações clínicas;
- alertas sanitários.


5. SUBSTITUIÇÃO DE CONTEÚDO

Quando uma fonte oficial atualizar uma orientação, a base
deve ser atualizada para refletir a informação mais recente.

A versão antiga não deve continuar sendo utilizada como
evidência atual sem indicação de que se trata de conteúdo
histórico.


6. REPROCESSAMENTO

Quando documentos utilizados pelo RAG forem alterados,
os chunks e embeddings correspondentes devem ser
gerados novamente para que a busca semântica utilize
o conteúdo atualizado.


7. DATA DE ACESSO

A data de acesso representa quando aquela fonte foi
consultada para construção ou atualização da base.

Ela não deve ser interpretada automaticamente como
a data de publicação ou atualização do documento original.


8. TRANSPARÊNCIA

O usuário deve ser informado de que o HealthCheck IA
analisa informações utilizando a versão das evidências
disponível em sua base de conhecimento e que informações
mais recentes podem existir nas fontes originais.


A base de conhecimento do HealthCheck IA não é atualizada em tempo real. As fontes devem ser revisadas periodicamente e, quando houver alteração relevante, os documentos, chunks e embeddings correspondentes devem ser atualizados antes de novas análises.
